# buchi:status — 接続状態を確認する

照会のみのスキル。**何も書き込まないため、ユーザーへの同意確認は不要**。

1. MCP ツール `buchi_status` を呼び出す（引数なし）。
2. 応答（設定値・反映状態・退避情報・healthz 疎通。すべてマスク済み）を
   **そのまま**ユーザーに提示する。要約する場合も、値はマスク済み表記のまま
   引用する。
3. 応答に「乖離（再起動待ち）」が含まれる場合は、Claude Code の再起動で
   反映される旨を補足する。「不正な JSON」等の異常が含まれる場合は
   `/buchiai-gateway:doctor` での診断を提案する。

## セキュリティ上の絶対条件

- トークンや userConfig の値を出力・引用・推測しない。表示は MCP ツールの
  応答（マスク済み）を**そのまま**使う。
- マスクされた値（`buchi_••••XXXX` など）から元の値を復元・補完しようとしない。
- このスキルで settings.json を変更しない（変更は setup / off / on で行う）。
