# buchi:doctor — 接続診断（D1〜D7）

照会のみのスキル。**何も書き込まないため、ユーザーへの同意確認は不要**。

1. MCP ツール `buchi_doctor` を呼び出す（引数なし）。
2. 応答（D1〜D7 の診断結果。すべてマスク済み）を**そのまま**ユーザーに提示する。
   D6（Remote Control 非互換）と D7（サブスク利用時は金銭的削減なし）は
   省略せず必ず含める。
3. NG / 注意項目があれば、応答に含まれる対処（例: D2 → バックアップからの
   復元、D3 → シェル rc の export 削除、D4 → プロキシ設定確認）を短く補足する。
   対処のうち設定変更を伴うもの（`/buchi:setup` / `/buchi:off` の実行など）は
   提案に留め、このスキル内では実行しない。

## セキュリティ上の絶対条件

- トークンや userConfig の値を出力・引用・推測しない。表示は MCP ツールの
  応答（マスク済み）を**そのまま**使う。
- マスクされた値（`buchi_••••XXXX` など）から元の値を復元・補完しようとしない。
- このスキルで settings.json を変更しない（変更は setup / off / on で行う）。
